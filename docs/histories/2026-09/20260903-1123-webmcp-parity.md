**Key Actions:**

  polyfill results at the page boundary.
- **Validation**: Added deterministic Node bridge tests and a pinned MCP-B
  polyfill fixture for manual Chrome smoke tests.

### 🧠 Design Intent (Why)

WebMCP is a page capability, not another browser-control transport. The Chrome
extension therefore keeps Open Browser Use's existing session and tab routing,
then adds a narrow page bridge that can access the MAIN-world WebMCP API. The
wire command names and result fields match the external capability contract,
while tab identity stays native to Open Browser Use.
