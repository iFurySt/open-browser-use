# 发布 Open Browser Use v1.1.0

## 目标与范围

从已合并并通过 CI 的 main 发布 v1.1.0，统一版本源，并核验 GitHub Release、npm CLI/JS SDK、PyPI、Homebrew 与 Chrome Web Store 提交状态。
Electron SDK 本轮随源码交付并同步版本，不新增尚未配置的独立 npm 发布链路。

## 流程与约束

沿用 docs/CICD.md、docs/CHROME_WEB_STORE_RELEASE.md 和 docs/releases/README.md 的 tag 发布流程。
先完成完整 CI、本地制品验证与主分支 CI，再推送不可原地修改的 v1.1.0 tag。
不取消 Chrome Web Store 已有审核；若有 active submission，记录标准跳过结果。
