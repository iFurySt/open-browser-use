# IAB 演示保留页面与手动浏览

> 阶段记录：后续已支持手动 1–5 重复点击及 SDK 光效颜色参数，仅一键重放
> 清理旧页。当前行为与验证方式以[示例 README](../../../examples/electron-iab/README.md)为准。

## 目标

- 四边使用同一组浅深蓝渐变；保留原鼠标样式。
- 删除关闭全部步骤，五步结束保留 Tab 1/2/3；仅明确重新播放/重启时清理旧页。
- Tab 选择和隐藏不受播放锁限制，页面操作仍以明确 tab ID 为目标。
- 地址栏可编辑、Enter 导航、刷新、后退/前进可用。手动改变页面时等待当前
  demo 动作结束并停止后续播放；串行处理手动请求，避免误操作其他 tab。
- 真实 Electron smoke 覆盖播放中切换、手动接管、保留结果和实际 DOM
  表单提交/按钮点击；原生窗口验证实际可点按。
