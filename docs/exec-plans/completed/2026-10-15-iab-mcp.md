# Authenticated IAB MCP

## Goal and scope

Add `obu iab mcp` for agent clients, reusing host-issued IAB bootstrap and
scope grants. Keep Chrome MCP routing unchanged. MCP uses stdin/stdout while
the authenticated browser connection uses inherited FD 3 or its socket bootstrap.

## Decisions and constraints

- Reuse the existing MCP protocol envelope with a separate IAB tool catalog.
- Every page tool requires an explicit tab id; scope and credentials remain
  fixed by the host. No Chrome discovery, profile selection or global CDP.
- Add opt-in piped stdin to `launchClient`, preserving existing one-shot defaults.
- Reuse page CDP for snapshot, screenshots, clicks and text input. Preserve tabs
  on MCP disconnect; host lifecycle still owns disposal and revocation.
- Reset browser request deadlines per request so idle MCP sessions remain usable.

## Validation

- Go tests: lifecycle, catalog, input validation, fixed scope, failed auth,
  notifications, idle reuse and browser errors; retain Chrome MCP regression tests.
- Real Electron smoke: private and socket MCP, page operations, screenshots,
  scope/grant rejection and EOF/revocation behavior.
- SDK tests/typecheck, repository checks, documentation and history updates.
